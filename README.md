# AKB and STRATOS Customer Documentation

Documentation revision: **1.3**, prepared **2026-08-28**.

This branch contains only the reusable customer handover, not application code,
production configuration, import records or internal audit evidence. It is a
separate public documentation snapshot; it does not replace the application
backup branch.

The package describes an internal-network pilot and includes product,
infrastructure, installation, operations, security, recovery and user guidance,
plus an authoring methodology and templates. Customer-specific installation
parameters must be recorded separately with appropriate access controls.

Publication of this reusable package is not an approval of a particular
customer deployment or a controlled-document release in AKB. Those approvals
remain part of the customer's governance process.
